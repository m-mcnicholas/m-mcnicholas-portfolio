# Projects the redesigned portfolio must include

These are the projects currently on `main`. The old site has been removed from this branch; the originals can be read with `git show main:<path>` (for example `git show main:index.html`, where each project's full copy lives in `#project-records`).

## 1. Cipher Twins
- **Type:** School project · Multiplayer puzzle
- **Date:** August 26, 2026
- **What it is:** A 2-player cooperative word game. Each player holds half of a hidden word's letters and can't say them, so the pair invents a shared language of icons and saved sigils to get the word across.
- **Destination:** https://m-mcnicholas.github.io/cipher-twins-game/ (its own repository, external link; no source in this repo)

### 2a. Boolean Logic Playground
- **Type:** School project · Interactive systems
- **Date:** August 24, 2026
- **What it is:** A guided circuit builder for labeling, connecting, and visualizing Boolean logic as live signals flow through gates, latches, and flip-flops.
- **Source on main:** `projects/boolean-logic/`

### 2b. Procedural L-System Forest
- **Type:** School project · Generative art
- **Date:** August 20, 2026
- **What it is:** A scattered grove of trees grown from L-system grammar rules and rendered in Three.js, regenerating into a new forest from a fresh random seed each time.
- **Source on main:** `projects/generative-tree/`
