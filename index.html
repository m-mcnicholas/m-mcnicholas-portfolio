School project · Multiplayer puzzle

Cipher Twins

August 26, 2026

A 2-player asymmetric co-op word puzzle: each player sees a different, incomplete slice of a hidden word through a private glyph font and must reconstruct it with a partner using only a shared icon palette.

Ten hand-authored levels split by letter position parity, so neither player can solve alone. Built serverless with WebRTC room codes (PeerJS) to run on static hosting; each role only ever fetches its own glyph data, and the answer is verified client-side from a SHA-256 hash rather than shipping the plaintext word.

School project · Interactive systems

Boolean Logic Playground

August 24, 2026

A guided circuit builder for labeling, connecting, and visualizing Boolean logic as live signals flow through gates, latches, and flip-flops.

Explores combinational and introductory sequential logic through eight common gates, explicit memory components, step-based clock controls, editable system labels, local autosave, and ten practical examples ranging from porch lights to a clocked memory lab.

School project · Generative art

Procedural L-System Forest

August 20, 2026

A scattered grove of trees, each grown from L-system grammar rules and rendered in Three.js, regenerating into a new forest from a fresh random seed each time.

Explores recursive rewriting grammars and turtle-graphics interpretation: an axiom is expanded through branching production rules, then walked to build tapered branch and leaf geometry for each tree, scattered across the ground in a phyllotaxis layout. Includes an orbit camera and a one-click reseed control.
